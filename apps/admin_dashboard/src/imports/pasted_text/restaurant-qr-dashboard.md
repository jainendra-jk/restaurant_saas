Design a modern **Restaurant QR Ordering Dashboard** for restaurant owners who receive customer orders from QR code menus.

The dashboard must be **clean, minimal, and responsive** and work smoothly on **desktop, tablet, and mobile devices**.

STYLE:
Use a modern SaaS dashboard aesthetic similar to **Stripe, Shopify, and Square POS dashboards**.
The interface should feel fast, simple, and professional for restaurant staff.

Typography: clean sans-serif (Inter / SF Pro style)
Design style: soft shadows, rounded cards, spacious layout
Color system: neutral base with one primary accent color for actions

---

LAYOUT STRUCTURE

Desktop Layout:

Left Sidebar Navigation
Main Content Area
Top Header Bar

Sidebar should include:

• Dashboard
• Live Orders
• Tables
• Menu Management
• Analytics
• Settings

Sidebar should collapse into an icon menu on smaller screens.

Header should contain:

• Restaurant name
• Search bar
• Notifications
• Profile avatar

---

LIVE ORDERS SCREEN (Primary Screen)

This is the most important screen.

Display orders in **Kitchen Display System (KDS) style cards**.

Each order card should show:

Table Number
Ordered Items with quantity
Order Time
Order Status

Example:

Table 3
2x Paneer Butter Masala
1x Butter Naan
1x Coke

Status: NEW ORDER

Order Status Options:

• New Order
• Accepted
• Preparing
• Served
• Completed

Cards should visually change color based on status.

Orders should appear in a **grid layout on desktop** and **stacked cards on mobile**.

---

TABLE MANAGEMENT SCREEN

Display all restaurant tables in a grid layout.

Each table card shows:

Table Number
QR Code Icon
Active Order Indicator

Actions available:

Generate QR
View Table Orders
Disable Table

---

MENU MANAGEMENT SCREEN

Restaurant owner should be able to manage the digital menu.

Layout:

Category Sidebar on left
Menu Items in main panel

Example Categories:

Starters
Main Course
Desserts
Beverages

Each item card shows:

Food Image
Item Name
Price
Veg / Non-Veg indicator

Actions:

Edit Item
Delete Item
Toggle Availability
Add New Item

---

ANALYTICS SCREEN

Display restaurant insights using simple charts and cards.

Metrics to show:

Total Orders Today
Revenue Today
Most Ordered Dish
Peak Ordering Hours

Charts:

Orders per Hour
Revenue Trend

---

RESPONSIVE BEHAVIOR

Desktop:
Sidebar visible + grid layout

Tablet:
Sidebar collapsible + adaptive grid

Mobile:
Bottom navigation or collapsible sidebar
Orders displayed in stacked card format

All elements must scale smoothly across screen sizes.

---

UI COMPONENTS

Design reusable components:

Order Card
Table Card
Menu Item Card
Status Badge
Action Buttons
Charts
Search Input

Use a consistent component system.

---

USER EXPERIENCE

Prioritize speed and clarity.

Restaurant staff should be able to:

See new orders instantly
Accept orders quickly
Update order status easily
Manage menu items without confusion
