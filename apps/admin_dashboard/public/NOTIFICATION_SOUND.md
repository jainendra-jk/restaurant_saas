# Notification sound

To enable the notification sound, add an audio file here:

- **File name:** `notification.mp3` (or `notification.wav`)
- **Location:** `public/notification.mp3` (this folder)
- **Recommendation:** Keep it under ~2 seconds so alerts feel quick.

The app will use it when a notification is played (e.g. on "Start Preparing" or when new order notifications are shown). If the file is missing, playback is skipped without errors.
