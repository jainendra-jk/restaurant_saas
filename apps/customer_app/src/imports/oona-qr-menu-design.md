Design a **mobile-first interactive QR code restaurant ordering system** that visually matches the aesthetic of the OONA food menu.

The design should feel like a **digital extension of the printed menu**, preserving the same colors, tone, typography, and visual motifs.

STYLE & COLOR PALETTE

Use a **soft luxury botanical palette inspired by the printed menu**:

Background: warm beige / sand
Primary accent: muted sage green
Secondary accent: olive green
Text: dark stone grey

The interface should feel **minimal, elegant, calm, and premium**, similar to a boutique resort restaurant.

VISUAL MOTIFS

Use the same visual language from the menu:

• Architectural **arched frames** for sections
• **Thin botanical line illustrations** placed subtly in corners
• Organic abstract shapes
• Minimal decorative elements

Typography:

• Section titles: elegant serif font
• Dish names: clean modern sans-serif
• Descriptions: smaller, lighter text
• Prices aligned neatly

Use **large white space and centered layouts** for a premium editorial feel.

---

QR SCAN EXPERIENCE (INTRO ANIMATION)

When the user scans the QR code:

Show a **3 second loading animation screen**.

Background: soft beige

Center:
An elegant **arch frame containing the restaurant logo**

Animation sequence:

1. The **arch outline slowly draws itself**
2. A **botanical leaf illustration grows subtly**
3. The **logo fades in**
4. Text appears:

“Welcome to OONA”

Below:

“Preparing your menu experience”

Add a **minimal loading indicator** (three fading dots).

After the animation the arch expands smoothly into the main interface.

---

MAIN MENU SCREEN

Top section:
Restaurant logo inside a soft arch header.

Below it:
Category navigation tabs:

Indian
Oriental
Continental
Desserts

Each category opens inside an **arch-shaped content container**.

Menu items should appear as **interactive cards**.

Each dish card includes:

Dish Name
Short Description
Price
Add to Cart button (+)

Optional icons:
Veg / Non Veg indicator

---

ADD TO CART INTERACTION

When the user taps “+”:

• quantity selector appears (+ / -)
• item highlights with sage green accent
• subtle animation confirms the item was added

A **floating cart icon** appears at the bottom.

---

CART / ORDER SUMMARY

When the user taps the cart icon:

Open a **cart drawer or page**.

Show:

Selected dishes
Quantity controls
Item price
Total price calculation

Allow user to:

• increase / decrease quantity
• remove items

Show a **clear total bill section**.

---

PLACE ORDER SCREEN

Add a clean checkout screen with:

Table Number (auto-filled if possible)
Name (optional)
Special instructions field

Primary button:

“Place Order”

Use a **sage green button with rounded edges**.

---

ORDER CONFIRMATION SCREEN

After placing order show a confirmation page.

Design:

Large arch illustration
Botanical line art background

Text:

“Your order has been placed”

Below:

“Our team is preparing your meal”

Optional:

Estimated preparation time.

---

MICRO INTERACTIONS

Add subtle interactions:

• soft fades
• sliding transitions
• gentle hover highlights
• arch containers expanding smoothly

Avoid loud or playful animations — keep everything calm and elegant.

---

OVERALL EXPERIENCE

The interface should feel like a **luxury fine-dining QR ordering experience**, combining minimal UI design with botanical elegance.

It should maintain the **same visual identity as the printed menu** so the digital interface feels consistent with the restaurant’s brand.
